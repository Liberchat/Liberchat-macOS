# 🚀 Liberchat macOS v2.0.0

## 📱 Application de messagerie native pour macOS

Application Electron optimisée avec fonctionnalités exclusives macOS et interface moderne.

## ✨ Nouveautés v2.0.0

### 🍎 Fonctionnalités macOS natives
- **Menu macOS complet** avec raccourcis Cmd+ natifs
- **Icône barre de menu** avec menu contextuel
- **Support Touch Bar** pour MacBook Pro
- **Effet Vibrancy** et fenêtre transparente
- **Thème système automatique** (Dark/Light mode)
- **Notifications natives** macOS
- **Comportement natif** (fermeture = masquer)

### 🎨 Interface moderne
- **Splash screen intelligent** avec sélecteur de serveur
- **Historique des serveurs** (3 derniers utilisés)
- **Thème adaptatif** clair/sombre avec toggle 🌙/☀️
- **Interface optimisée** avec améliorations natives

### ⚡ Performance & Sécurité
- **Cache intelligent** pour réduire les requêtes
- **Sécurité renforcée** avec processus isolés
- **Permissions automatiques** micro/caméra
- **Scrollbars et polices** système natives

## 📦 Installation

### Méthode 1: DMG (Recommandée)
1. Téléchargez `liberchat-macos-v2.0.0.dmg`
2. Double-cliquez pour ouvrir
3. Glissez Liberchat dans Applications
4. Lancez depuis Launchpad

### Méthode 2: Archive ZIP
1. Téléchargez `liberchat-macos-v2.0.0.zip`
2. Décompressez l'archive
3. Copiez `liberchat.app` dans `/Applications/`

## ⚙️ Configuration requise
- **macOS 11.0+** (Big Sur ou plus récent)
- **Architecture x64** (Intel Mac)
- **~45 MB** d'espace disque

## 🔧 Raccourcis clavier
- `Cmd+Q` : Quitter
- `Cmd+W` : Fermer/Masquer
- `Cmd+M` : Réduire
- `Cmd+R` : Recharger
- `Cmd+,` : Préférences
- `Cmd+H` : Masquer

## 🛠️ Compilation depuis les sources

```bash
# Cloner le dépôt
git clone https://github.com/Liberchat/Liberchat-macOS.git
cd Liberchat-macOS

# Compiler (macOS uniquement)
chmod +x build-macos.sh
./build-macos.sh
```
